01 / 드론 센서 입력 조절

실제 비행 데이터가 아닌 교육용 가상 수치입니다. 한 번에 하나의 조건을 바꿔 차이를 관찰해 보세요.

실험 팁: 노이즈와 편향은 서로 다른 현상입니다. 노이즈는 측정값의 흔들림, 편향은 측정값이 일정한 방향으로 치우치는 현상을 나타냅니다.

05 / 원리와 한계

작동 원리
K개의 가까운 사례로 분류

기울기, 진동, 고도 변화의 차이를 거리로 계산한 뒤 가까운 K개 사례의 다수결로 상태를 선택합니다.

오판의 원인
노이즈·편향·학습 데이터

센서 값이 흔들리거나 한쪽으로 치우치고, 학습 데이터가 부족하거나 편중되면 예측이 틀릴 수 있습니다.

실제 적용
예측은 안전 보증이 아님

이 실험은 가상 수치와 단순 분류기를 사용합니다. 실제 드론의 비행 안정성이나 고장 원인을 판정하는 데 사용할 수 없습니다.

표준화 거리 d = √[(Δ기울기 / 70)² + (Δ진동 / 10)² + (Δ고도변화 / 16)²] Δ는 검사 대상과 학습 사례 사이의 차이입니다. 표준화를 하지 않으면 숫자 범위가 큰 특성이 거리 계산을 과도하게 지배할 수 있습니다.

학습 목표: 결과를 그대로 믿지 않고, 센서 입력·오차·알고리즘 설정·학습 데이터의 변화가 AI 판단에 미치는 영향을 실험하고 설명합니다.
