파일과 검증 대상이 서로 다르면 알고리즘의 차이인지 자료의 차이인지 알기 어렵습니다. 모두 같은 수업용 CSV를 사용하고, 파일에 미리 지정한 학습·검증 구분을 유지합니다.

무엇을 예측하나요?

UCI Student Performance의 포르투갈어 과목 자료를 가공했습니다. 두 포르투갈 학교의 관측 자료에서 최종 성적 G3가 10점 미만인지 구분합니다. 학교나 학생의 성취를 평가하는 실제 서비스가 아니라, 모델의 예측과 한계를 살펴보는 실습입니다.

성적 구간 ≠ 학생의 능력 전체 ≠ 실제 지원 필요성. 이번에 만든 정답은 성적 구간일 뿐입니다. 언제 측정된 정보인지 확인하지 않고 학기 초의 조기 예측이라고 설명해서도 안 됩니다.

기존 성적 없이 무엇을 알 수 있는지 보기 위해 G1·G2를 제외했습니다. G3는 정답을 만든 뒤 실습용 CSV에서 제거했습니다. 성별·가족 배경 등 나머지 열도 공통 입력에 포함하지 않았습니다.

정확도 84.6%면 잘한 걸까요?

검증 자료 130명 중 110명은 10점 이상, 20명은 10점 미만입니다. 모두를 10점 이상이라고 답하기만 해도 정확도는 84.6%입니다. 하지만 10점 미만인 학생은 한 명도 찾지 못합니다.

읽는 법과 재현 조건

  • 엑셀에서는 CSV를 열어 열 이름과 값을 살펴봅니다. 변경 없이 보관하세요.
  • 같은 CSV가 노트북에도 포함되어 있습니다. 코랩에서는 별도 데이터 업로드나 외부 주소 접속 없이 실행됩니다.
  • 자료 분리는 정답 비율을 고려한 층화 분할, 초기값 42로 고정했습니다.
  • 전처리는 학습 자료에서만 학습하며, 검증 자료를 학습에 넣지 않습니다.
  • 매개변수를 비교할 때는 validation을 사용하고, test는 선택을 확정한 뒤에만 확인합니다.
