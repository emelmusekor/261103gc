알고리즘 선택

같은 입력 5개로 성적 10점 미만 여부를 예측합니다. 알고리즘을 고르고, 매개변수 하나를 바꿔 결과를 비교하세요.

내가 맡을 알고리즘판단 방식실험할 질문바꿀 조건
로지스틱 회귀 →여러 항목의 정보를 합쳐 두 범주를 구분합니다.규제를 약하게 하면 검증 결과도 좋아질까?C
결정트리 →조건에 따라 가지를 나누며 분류합니다.질문을 끝없이 세분하면 처음 보는 학생도 더 잘 맞힐까?max_depth
랜덤포레스트 →서로 다르게 학습한 여러 나무의 판단을 모읍니다.나무를 여러 개 모으면 깊이를 늘렸을 때의 결과도 달라질까?max_depth
K-NN →입력 항목의 값이 가까운 사례들의 정답을 참고합니다.한 명의 이웃과 여러 명의 이웃 중 어느 쪽을 더 믿을까?n_neighbors
SVM →두 범주를 구분하는 경계를 학습합니다. 이번에는 RBF 커널을 사용합니다.학습 오류를 더 강하게 벌주면 새 자료의 오류도 줄어들까?C
